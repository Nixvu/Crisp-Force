
# CRISP FORCE 

Crisp Force adalah sebuah project sederhana yang berfokus pada penerapan crm operasional, project ini dibuat oleh Febriana sebagai tugas dari ujian akhir semester, mata kuliah customer relationship management dan juga sebagai bahan belajar dalam proses pengembangan dan implementasi sistem informasi dan juga penerapan customer relationship management.

## Tech Stack

**Front End** Tailwind css

**Back End:** PHP 

**Tools** VSCode, Laragon,Figma, 

## Installasi
Sebelum melakukan Installasi, pastikan hal berikut telah terpenuhi
```bash
  1. Install Laragon / XAMPP / WAMPP 
  2. PHP Minimal Versi 8 (Rekomendasi Terbaru)
  3. Apache / Nginx (Rekomendasi Terbaru)
  4. Mysql Versi 8 (Rekomendasi Terbaru)
  5. Koneksi Internet, beberapa komponen menggunakan CDN.
``` 
Jika sudah terpenuhi masuk ke proses Installasi

```bash
  1. Download project ini atau bisa lakukan clone :
     git clone https://github.com/Nixvu/Crisp-Force.git
  2. Setalah project terinstall letakan di folder berikut
      Dir : Laragon\www\ 
      Dir : XAMPP\htdocs\
      Dir : Wampp\wwww\
  3. Login ke ke phpmyadmin (mysql) dan lakukan import database 
     yang berada pada folder  "Crisp Force\include\database.sql"
```
